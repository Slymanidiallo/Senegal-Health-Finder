## 🇬🇧 English
### Overview
The repository description states an ambition to help users find hospitals according to a health need and to present information such as regions, doctors, prices, emergency availability and directions.

### Current status
The repository currently contains only this README file. No source code, verified hospital directory, database, API or deployed application is available in this repository at the time of this documentation update.

### Important
Healthcare facility details, medical availability, emergency services, prices and directions must be sourced from authoritative and regularly updated sources. This README describes the repository's stated concept, not a verified operational service.
